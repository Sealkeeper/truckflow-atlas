## 一、两个主指标（已由用户确认，不再扩展成十几个）

只保留两个顶层准确率指标。分项（南/北/重合/唯一、逐车框、逐条边）只用于解释错误，不能求平均掩盖失败。

**指标一：数量全对率**

```
某时刻数量全对 ⇔ south 对 且 north 对 且 overlap 对
数量全对率 = 三项同时正确的时刻数 / 应评时刻数
```

唯一数满足 `unique = south + north − overlap`，只作公式校验，不单独作为第三项。

**指标二：重叠车辆身份全对率**

```
某时刻身份全对 ⇔ 同画面重叠边集合完全一致
               且 南北同车 pair 集合完全一致
               且 无错误合并、无一对多、无重复多配
身份全对率 = 身份全对的时刻数 / 应评时刻数
```

两个指标的逻辑与（整时刻全对）只是联合视图，不是第三个准确率。
