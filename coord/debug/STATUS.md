## 复现

```powershell
cd D:\File\PROJECT\codex\codex-货车\sessions\debug_experience
.\debug\capture.ps1
```

脚本会自动：

- 安装无浏览器下载的 `playwright-core`（首次运行）；
- 启动随机端口的本地静态服务器；
- 使用本机 Chrome 无头模式打开 `debug/viewer/`；
- 验证采样切换、分析画面提示以及返回默认时刻；
- 覆盖桌面/手机两张 `latest-*` 截图与 `report.json`；
- 将两张截图复制到公共 `assets/live/`。

常驻预览：

```powershell
$env:CAPTURE_PORT = "4174"
node debug/capture.mjs --serve-only
```

打开 `http://127.0.0.1:4174/debug/viewer/`。

## 遗留问题

1. **唯一车辆总数为空**：跨机位实体合并尚未接入，不能用 3 + 5 计算唯一车辆。
2. **车辆框缺失**：后端分析接口未提供框、编号与置信状态；页面只显示证据缺口。
3. **南侧通道边界未确认**：画面底边红色货厢是否属于统计通道仍需用户确认。
4. **容量参数为演示值**：6 / 10 / 12 只用于展示公式，不是实测或标定后的米制容量。
5. **抽样曲线不是逐帧结果**：时间轴只连接 10 个人工抽样时刻，不能当作连续真值。
6. **未声称准确率**：本页仅呈现开发集人工计数；已公开的 Doubao 15/18 只属于开发集基线，不是验收准确率。
