# 离线身份记忆可行性审计

状态：零新模型调用的数据与策略审计。结论是**当前数据不足以测量真实身份准确率，也不能启动换挂识别验收**。

## 审计范围

脚本 `offline_identity_audit.py` 读取既有的用户计数真值、20 帧归档、66 个护照、72 条记忆缓存、8 个跨机位配对候选和 9 张人工红框图清单。它不调用网络或模型，不读取模型输入之外的新观测，也不修改任何既有指标。

输出：`generated/offline_identity_audit.json`。

## 可用数据

| 项目 | 数量 | 能证明什么 |
|---|---:|---|
| 时刻 / 相机帧 | 10 / 20 | 相机计数与跨机位重合数 |
| provisional 护照 | 66 | 当前帧语义证据、逐字文字和来源 |
| confirmed 护照 | 0 | 无 |
| 有类型 `cargo_id` / `tractor_id` 值 | 0 / 0 | 无 |
| 单帧 provisional session | 66 | 仅表示一次当前帧观测 |
| 人工红框图 | 9，覆盖 6 个时刻 | 计数评估，不含箱号/车头/会话 ID |
| 跨机位候选配对 | 8 | 4 个正例、4 个负例的局部同车标签 |
| 人工 `cargo_id/tractor_id/vehicle_session_id` 字段 | 0 | 身份准确率无法计算 |
| 人工换挂事件 | 0 | 无法测换挂后的 session 是否错误延续 |
| 与目标隔离的 prior-only 历史 / future target | 0 | 无法做真正的历史记忆前瞻验证 |

用户最终复核文件只有相机计数、可见总数、重合数和说明；人工红框清单没有逐车硬 ID。模型响应中出现过 `粤L66002`、`粤T73778` 等文字，但它们是模型观测，不是独立 OCR 或人工核验真值，不能用于计算 `cargo_id` 或 `tractor_id` 的 precision/recall。

## 当前能验证的策略不变量

以下检查全部通过：

- 66 个护照都有三层身份字段；
- 所有 `cargo_id` 和 `tractor_id` 的 `value` 为空、状态未验证；
- 未分类原始文字没有进入两个硬身份候选层；
- 66 个 `vehicle_session_id` 只关联各自当前帧观测，唯一值也是 66；
- confirmed 身份数为 0；
- 护照和 72 条缓存全部包含来源、观测/创建时间、版本、TTL、过期时间、状态、冲突和 `supersedes`；
- 跨机位自动放行为 0。

这些是**策略实现检查**，不是身份识别指标。通过它们只能说明系统没有把未验证文字静默升级成硬 ID，不能说明身份匹配正确。

## 现有配对标签的边界

8 个候选配对可用于检验“是否同一辆车”的局部语义证据，当前 exact 3/8、自动 yes 0、review 5/8。它不能替代：

- `cargo_id` 是否 OCR 正确；
- `tractor_id` 是否车头正确；
- 同一整车会话是否连续；
- 换挂后是否错误沿用旧会话。

因此不得把 8 个配对结果写成三层身份准确率。

## 离线实验所需的最小新增真值

1. 对若干真实车头与货厢分别标注稳定 `tractor_id` 和 `cargo_id`，包括人工核验的 OCR 来源和不确定状态。
2. 标注连续观测的 `vehicle_session_id`，每个会话必须有当前挂接或连续可见证据。
3. 包含同一车头换不同货厢、同一货厢接不同车头、OCR 不清和仅箱号相同的负例。
4. 按时间切分 prior-only 建库段与 future target 段；测试目标时刻不得进入建库，也不得使用其人工框或答案。
5. 至少两名标注者独立标注、第三人裁决；保存分歧和版本。

## 评估设计

| 指标 | 定义 | 当前状态 |
|---|---|---|
| `cargo_id` precision / recall | 与人工核验货厢 ID 比较 | 未测 |
| `tractor_id` precision / recall | 与人工核验车头 ID 比较 | 未测 |
| session link precision / recall | 同一物理会话的正负连接判断 | 未测 |
| false merge rate | 不同会话被自动合并的比例 | 未测 |
| swap continuity error | 换挂后仍沿用旧会话的比例 | 未测 |
| abstention / review rate | 证据不足时进入复核的比例 | 未测 |

任何阈值应先预注册。不能因为看到 future 段结果再调整阈值或提示词后复用同一批样本包装成一次实验。

## 结论

当前记忆路线的机制和证据纪律可以实现，但**离线身份实验尚未具备可执行真值**。下一步需要数据标注与时间隔离，而不是重复“全局 + 固定远区”付费调用。

复现审计：

```powershell
python research\vehicle_memory\offline_identity_audit.py
```
