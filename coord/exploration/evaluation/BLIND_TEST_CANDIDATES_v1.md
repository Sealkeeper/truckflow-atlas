# 标签未见候选 v1（不是独立盲测）

日期：2026-10-21。本文只提出候选时刻和所需标签，不要求用户立即标注，也没有新增模型调用。

## 先说结论

当前**没有真正的新视频独立盲测集**。公开数据里已经存在覆盖整条视频的 60 秒抽帧和模型估计，候选时刻只能做到“未见过这批计数标签”，不能做到“未见过图像或模型输出”。同一展厅内大量车辆位置近似静止，间隔 50–90 秒的相邻帧属于近重复画面，不能当作独立场景。

## 公开时间暴露审计

审计对象（均为公共目录，不读取其他 session）：

| 来源 | 时间覆盖 |
|---|---|
| `data/timeline_frames_v1.json` | 46 个时刻，0–2640 秒每 60 秒一帧，另有 2658.96 秒 |
| `data/timeline_camera_v1.json` | 同一 46 个时刻，南北各一个模型估计点，共 92 点 |
| `data/manual_review_v1.json` | 13 个时刻：60、300、360、600、900、1200、1500、1800、2100、2160、2400、2640、2659 秒 |
| 事件账本窗口 | 540/570/600、2100/2130/2160、2580/2590/2600 秒 |
| 当前 dev 真值 | 5、300、600、900、1200、1500、1800、2100、2400、2600 秒 |

原候选中的 60、180、420 秒**恰好命中公开 60 秒网格**，已有模型估计；60 秒还有人工复核计数。因此它们不是“未见”时刻，不能称为盲测。

其余 750、1050、1350、1650、1950、2250、2550 秒虽不在 60 秒网格，但距离最近的公开抽帧只有 30 秒；展厅车辆近似静止，画面高度相似。

这批只能称为 **`label_unseen_time_offset`**：

- 没有这 10 个时刻的计数/unique/overlap 人工标签；
- 同一视频、同一展厅、近似静止车辆，画面与公开抽帧近重复；
- 不能验证跨场地、跨摄像头安装或真正新视频的泛化。

## 冻结要求

在标注和运行前冻结：

- 这 10 个时刻的 north/south 图、裁剪几何和 SHA256；
- 模型、prompt、temperature、max_tokens、调用上限；
- 评估代码和固定分母 20；
- 标签隐藏状态：任何提示词、记忆、检索库、摘要都不得包含这些时刻的红框、计数、unique/overlap 或未来观察。

如发现候选时刻与任何公开模型输出或人工复核重叠，必须降级该候选，不能继续称“未见”。

## 必需人工标签

| 标签 | 粒度 | 用途 | 是否阻塞主验收 |
|---|---|---|---|
| 每机位车辆总数 | 20 个机位样本 | count exact / MAE / 漏多计 | 是 |
| 每机位逐车红框 + 独立车体编号 | 20 个机位样本 | 检查框覆盖、重复框、牵引车/挂车配对 | 是 |
| 同刻 north/south 唯一车辆集合 | 10 个时刻 | unique exact / MAE | 是 |
| 同刻两机位重合车辆数 | 10 个时刻 | overlap exact / MAE | 是 |
| 跨机位车辆 ID 映射 | 10 个时刻 | 联合集合的 ID/配对准确率 | 仅双机位路线 |
| 进/出/重现事件时间戳 | 事件窗口 | 事件账本漏报/幽灵 ID | 仅事件路线 |
| 车辆类型 | 逐框 | 车型准确率 | 仅需要车型指标时 |
| 是否必须人工复核 | 20 个机位样本 | 自动放行覆盖率/错误率 | 仅复核调度路线 |

标签定义：

- 只统计画面内可见的货车车体；叉车、轿车、面包车、行人排除。
- 牵引车与其挂车算一辆；明确独立且可辨的货厢单独计。
- 遮挡但能确定是货车时计入，并标 `partial`；完全看不见的不猜。
- 逐车红框只用于评估与解释，不得进入模型输入、检索记忆或同帧提示。
- 同刻唯一集合必须由 north/south 的同一物理车辆建立映射，不能把两路数量简单相加。

## 最小批次

人力有限时先标 C01、C04、C07、C10，共 4 个时刻 / 8 个机位样本。报告时必须标注 `label_unseen_time_offset_mini`，不能写成 blind。

要获得真正独立盲测结论，仍需一段未参与开发的新视频或新时段人工标签；当前没有。
