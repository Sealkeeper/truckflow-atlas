# v3 复核标注清单

当前工作台的“南北数量 + 标注截图”只能支持数量审核，不能直接生成身份 gold。完整身份评测还需要以下逐车关系。

## 每个时刻

- 确认南北两张图来自同一时刻。
- 记录视频时间、原图文件名、图像 SHA256、分辨率。
- 标记机位资格范围；资格范围不一致时不得直接计算唯一数。
- 单独确认：数量真值完整、身份真值完整。

## 每辆货车

- 分配仅在该时刻内唯一的车辆 ID。
- 画顶面或可见车辆外廓 bbox；能准确画 polygon 时再补充 polygon。
- 标记是否属于牵引车与挂车的同一物理车辆。
- 标记遮挡状态：`none`、`partial`、`severe`、`unknown`。
- 标记截断状态：`none`、`edge`、`unknown`。
- 与其他车辆重叠时，记录双方 ID 形成的重叠边。
- 无法确认的组成、数量或身份保留 `unknown`，不得靠历史帧补齐。

## 南北同车

- 逐一建立 `south_id ↔ north_id` pair。
- 一个车辆观察最多出现在一个跨镜 pair 中。
- 两侧数量、重合数和唯一数必须满足：

```text
unique = south + north - overlap
```

- 重合数必须与真实跨镜同车 pair 数一致。

## 完整性

只有同时满足以下条件，某一时刻才进入身份指标分母：

- 南北图完整且来自同一时刻；
- 每辆应计车辆的 ID、bbox 和重叠边已复核；
- 全部南北同车 pair 已确认，并能区分“没有同车”与“尚未检查”；
- 双人独立标注后由第三人仲裁差异；
- gold 文件与图像 SHA256 一并封印。

## 禁止

- 不把模型框或模型配对直接当 gold。
- 不根据数量是否正确反推车辆 ID 或跨镜配对。
- 不用面积大小推定车型或身份。
- 上传的标注图不得进入模型提示词、检索记忆或训练输入。
