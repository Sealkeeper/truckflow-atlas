1. 点选通道边界

依次点击近左、近右、远右、远左四个地面角点。黄线为单应框， 青线仅用于目测中心线。

还需点击 4 个角点
样帧假设 通道宽按约 6.0 m、可见段长按约 55 m 估计；两项均可在右侧修改。

4. 容量建议

纵向排布用于移动通道；面积法仅作理论上界参照。

N纵向 = floor((L可用 + 净距) / (车长 + 净距)) N面积 = floor(W可用 × L可用 × 填充率 / (车长 × 车宽))

未确认前仅显示“建议值”，导出与工作台接口均标记 confirmed: false。

5. 敏感性区间

宽度 ±8%、长度 ±12%、车长 ±5%、净距 ±0.5 m，蒙特卡洛 20000 次。

容量取整数，区间可能只在楼层边界处变化。角点点击误差在“长宽均已知”时 不改变面积，只改变地面位置映射，因此不伪造面积误差。

6. 负载率核算

严格采用 Σ(当前该型数量 / 该型容量)。

嵌入接口

几何与容量函数均在 capacity.js，无第三方依赖。

const cal = TruckCapacity.calibrate({
  imagePoints: [nearLeft, nearRight, farRight, farLeft],
  widthM: 6.0, lengthM: 55,
  imageSize: { width: 1280, height: 960 }
});
const cap = TruckCapacity.computeCapacities({
  widthM: cal.widthM, lengthM: cal.lengthM,
  model: { trafficMode: "dead-end" }
});

capacity.js 只给建议与区间，不替用户确认额定容量。
