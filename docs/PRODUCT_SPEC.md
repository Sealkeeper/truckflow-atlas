# 货车识别与通道容量工作台：产品规格

## 1. 目标

对广交会撤换展场景的双机位视频做可追溯的货车统计，并在任意时间点给出：

- 在场货车总数；
- 小型、中型、大型货车数量；
- 每个车型的单车负载率与综合通道负载率；
- 跨机位去重后的车辆唯一编号；
- 可回看原画面/分析画面、逐车证据和复核问题；
- 按任意时间段聚合的平均值、峰值与周期统计。

“完全准确”在本项目中的可验证定义见 `ACCURACY_CHARTER.md`。系统绝不把未经核验的模型输出标成确定结果。

## 2. 用户流程

1. 上传一段或两段视频，填写画面起始时间与机位名称。
2. 配置通道：选择有效通行区域，设置大/中/小型车的额定容量。
3. 启动分析。系统先抽样、再用多模态模型识别，分歧项自动复核。
4. 页面显示分析进度；按时间轴查看数量变化和负载率。
5. 切换到“分析画面”查看车辆框、编号、车型与置信状态。
6. 打开“复核画面”，逐条处理遮挡、跨机位、边界和车型争议。
7. 导出 CSV/JSON：逐时刻计数、车型、负载率、车辆证据与复核记录。

## 3. 画面与时间

- 支持单帧、播放、拖动和按时间段筛选。
- 双机位共享播放时间；源视频时间戳存在 1–2 秒偏差，需通过偏移量校准。
- 采样时刻与原始视频帧一一对应。页面展示“视频时间”和“业务时间”两个字段。
- 分析结果随播放进度更新；没有对应采样帧时，明确显示最近采样时间，不伪装成逐帧真值。

## 4. 计数口径

默认口径为“当前时刻在任一机位画面中可见、且判定为货车的车辆，同一物理车辆只计一次”。

- 只有车头、挂车或局部可见时，仍计为一辆，但车型可标记为待复核。
- 同一辆车的车头与货厢不分开计数。
- 两机位重叠车辆通过外观、相对位置、时间连续性合并。
- 完全遮挡、画面外或只看到无法确认的局部时，不计入确定数，进入复核。

## 5. 车型

- 小型：厢式轻卡、轻型货车等。
- 中型：两轴/三轴中卡、中型厢车。
- 大型：重型牵引车、半挂、长货厢重卡。
- 判定优先使用整车轮廓与车顶比例；画面只允许车顶时使用车顶长宽比和车型外观。
- 车型不确定不得强行归类；在统计中单列为“待定”，并从确定总数之外单独展示。

## 6. 通道负载

设大、中、小型车的额定容量分别为 `C_L`、`C_M`、`C_S`，当前数量为 `N_L`、`N_M`、`N_S`：

- 单车型负载率：`N_L/C_L`、`N_M/C_M`、`N_S/C_S`
- 综合负载率：`N_L/C_L + N_M/C_M + N_S/C_S`，以百分比显示，可超过 100%

容量参数由用户确认。系统可给出基于通道有效面积和车型占位的建议值，但必须展示计算依据和不确定性，不能把透视画面比例直接当真实米制尺寸。

## 7. 复核

每个可疑项包含：

- 机位、视频时间、业务时间；
- 原图与放大裁剪；
- 模型给出的框、车型、理由、票数；
- 不确定原因（遮挡/边界/车型/跨机位/重复）；
- 复核操作：确认、删除、改车型、合并编号、拆分编号、标记未知。

网页内可直接向用户提问，问题需给出可点击的复核时间点。

## 8. 验收

- 页面可以离线打开演示样例，也可以在本地 API 服务下上传并分析视频。
- 每个数字可下钻到证据；任何未复核分歧都清晰可见。
- 时间轴、播放器、机位切换、数量与负载率保持同步。
- 在冻结的金标准集上报告逐帧精确匹配率、绝对误差、重复率、漏检率、车型混淆矩阵。
- 没有实测数据支持的“准确率”表述一律禁止。
