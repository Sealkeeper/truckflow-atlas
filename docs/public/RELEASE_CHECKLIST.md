# 公开更新检查清单

本仓库已经公开，且包含获准公开的监控素材与人工复核真值。此清单用于**后续发布或新数据导入**，
不再沿用早期“任何素材都不得公开 / 仓库必须小于 20 MiB”的私有协作草案。

## A. 许可、隐私与凭证

- [ ] 新增代码的许可与根 LICENSE 兼容；数据按 DATA_LICENSE.md，不能用代码许可替代数据许可
- [ ] 新增画面 / 真值有明确授权和来源记录；已有公开许可不自动覆盖其他现场数据
- [ ] 未单独提取车牌、箱号、人脸用于身份识别或商业画像，未提交密钥 / 凭证
- [ ] 对新增文件和相关历史进行密钥扫描；没有测量就不宣称“全历史零泄漏”

## B. 实时与离线边界

- [ ] 实时链路不依赖 YOLO 及同类检测器，包括远端或异步在线服务
- [ ] 若涉及离线教师 / 预标注 / 蒸馏，明确教师 / 学生、数据隔离、资源预算、许可与停止条件
- [ ] 教师输出与人工 gold 分开，留出集不进入训练，最终学生部署依赖已审查
- [ ] 不以改名、压缩同类在线检测器绕过实时约束；CI 关键词提示不能代替部署审查

## C. 证据与复现

- [ ] 未覆盖冻结 raw、源帧 / 视频或真值；修订以新版本和可追溯回执提交
- [ ] 视觉结果附数量 / 身份两项指标的分子与应评分母、输入 / gold / 预测版本及 hash
- [ ] 未测、无真值、开发集、合成测试与盲测分开；维护贡献不虚构视觉收益
- [ ] 命令、相对链接与目录在干净克隆上存在；完整复算包未发布时明确说明
- [ ] 默认离线测试通过；会写入证据的审计在独立副本运行并保留原结果，不仅检查进程退出码
- [ ] 性能比较注明硬件、并发、输入、token 与真实费用来源，不把单项或不可比结果当联合达标

## D. 协作与留出评测

- [ ] README、CONTRIBUTING、issue / PR 模板统一引用当前边界，不复制过期规则
- [ ] 新的 issue / PR 有具体交付、复现方式、失败条件与未运行项
- [ ] 若提供未来盲评服务，使用未暴露真值的独立留出集，分别公布数量与身份指标

当前已公开真值的数据只能按其实际暴露状态使用，不能事后重新声称“从未见过真值”。
