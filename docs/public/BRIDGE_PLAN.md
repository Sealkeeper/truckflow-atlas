# 开源协作桥：三档隔离方案

目标：让外部的人（天南海北）能真正帮上忙。

> **2026-10-22 21:50 用户决定**：监控帧**可以且必须公开**，包括已人工复核的真值。
> 理由：不公开数据，外部就无法核对我们的数字，也无法真正提升指标。
> 因此本方案的默认形态是**全量公开**（代码 + 帧 + 真值），
> 隐私条款收敛为 `DATA_LICENSE.md` 的"不得用于识别特定自然人"。
> 下面保留三档隔离方案，作为**将来若要分仓**时的参考；当前不走脱敏路线。

## 0. 现实约束（先说清楚，别自欺）

| 事实 | 数据 |
| --- | --- |
| 仓库当前可见性 | **PRIVATE**（`Sealkeeper/truckflow-atlas`） |
| 仓库体积 | 255 MiB（assets 75.6 / review 49.8 / accuracy 49.5 / research 22.2 / coord 19.7） |
| 真实监控帧 | **62 张**（`assets/frames/*.jpg`，含箱号、车牌、厂区布局） |
| git 历史密钥残留 | **0**（全历史 1159 文件扫描：`ark-*` / `sk-*` / 智谱格式 全部零命中） |
| LICENSE | **无**（法律上外部人目前无权使用或贡献） |
| CI / issue 模板 / CONTRIBUTING | **均无** |

结论：现在这个仓库**不能直接公开**——不是技术问题，是素材授权问题。

## 1. 三档隔离

### Tier A｜公开仓（新建或把现仓瘦身后公开）

只放**不含现场画面**的东西：

- 评测协议与评测器（`coord/evaluation-v3/`，含红队用例）
- gold / prediction 的 JSON Schema 与**合成 fixture**
- 标注台（`coord/optimization-20261022/labeling/`，纯前端，不含图）
- 几何/对齐算法（`invention/lane_queue/` 等）
- 复现脚本与命令、失败案例的文字化描述

外部人能贡献：评测器 bug、指标定义漏洞、算法、测试、文档、可视化。

### Tier B｜私有数据仓（现仓保留，或拆成 `truckflow-data` 私有仓）

真实帧、真值、冻结 raw、客户现场。**只允许被授权者访问**。

外部人**永远不直接看**这些数据；他们只提交能跑在私有数据上的**代码**。

### Tier C｜盲评通道（GitHub Actions）

贡献者提交算法 → CI 在私有 runner 上用真实数据跑 → **只回传分数**，不回传图或真值。
这是"外部助力但不泄密"的关键：他们看到的是 `数量全对率 8/15`，不是画面。

## 2. 公开前必须逐项过的红线

1. **画面**：`assets/frames/**`、`review/**` 的任何截图都不得进入公开仓。
2. **真值**：`accuracy/reviewed/**` 属客户业务数据，不公开。
3. **绝对路径**：仓库里大量 `D:\File\PROJECT\...` 硬编码，公开前要改成相对路径或环境变量。
4. **体积**：255 MiB 对公开仓太重；公开版应 < 20 MiB（代码+文档+合成图）。
5. **历史**：如果要"把现仓转公开"，必须**重写历史**剔除大文件与素材；更安全的做法是**新建一个干净的公仓**。
6. **密钥**：历史已干净；但公开前仍要在 CI 里加 secret 扫描（gitleaks），防止以后再犯。

## 3. 外部人能在不知道数据的情况下做什么（这是桥的价值）

| 可贡献 | 为什么不需要看原始画面 |
| --- | --- |
| 评测器与指标实现 | 用合成 fixture 就能验证 |
| 几何/对齐算法 | 输入是结构化 JSON（bbox/序数/代价矩阵） |
| 提示词与 schema 设计 | 针对输出契约，不针对具体帧 |
| 性能优化 | 针对请求构造/解析/批量，不需要图 |
| 失败模式分析工具 | 输入是日志与结构化记录 |
| 可视化与标注台 | 纯前端，用占位图 |

**唯一需要真实数据的是"效果验证"，而它走 Tier C 盲评。**

## 4. 建议的落地顺序

1. 先做**私有协作**（把现仓 private 保持，加 LICENSE + CONTRIBUTING + issue 模板 + CI），
   邀请 1–3 个可信的人进来，验证协作流程是否顺。
2. 流程跑通后，再建**公开仓**（Tier A），用 `git subtree`/脚本从私有仓**单向导出**白名单目录。
3. 最后才开 Tier C 盲评（需要私有 runner 或自建评测服务）。

第 1 步今晚就能做，第 2 步需要你确认素材授权，第 3 步需要一台能跑私有数据的机器。
