# 开源协作桥：当前边界与可选扩展

## 当前状态（2026-10-23 核对）

Sealkeeper/truckflow-atlas 已是公开仓库，已有 LICENSE、DATA_LICENSE.md、贡献指南、issue / PR 模板和 CI。
仓库包含已获准公开的监控素材与人工复核真值；早期“仍为私有 / 无许可 / 素材必须全部排除”的草案不再适用。
历史体积或扫描数字不能当作当前审计结果；未重新测量就不沿用。

以 [根 README](../../README.md) 的结果摘要与复现边界、[贡献指南](../../CONTRIBUTING.md) 的研发 / 部署约束、
[数据许可](../../DATA_LICENSE.md) 的隐私与使用条件为准。

## 外部贡献如何进入

1. 用 issue 指出具体问题、已有证据、预期交付和失败条件；先检查是否与其他任务重复。
2. 在分支提交最小改动，保留原始证据；文档 / 工程贡献可按相应检查验收，不要求伪造视觉提升。
3. 视觉实验冻结输入、配置、预测与预算，数量 / 身份分别报分子和应评分母。
4. 实时解析不依赖 YOLO 类检测器；离线教师、预标注和蒸馏可以研究，明确隔离与最终部署依赖。
5. 人工真值独立于教师预测；不静默改 gold，不向未经许可的外部服务上传新现场素材。

当前公开结果的完整复算材料尚未全部发布，不能把不存在的本地路径作为外部任务的唯一依赖。
任务作者需提供仓库内实际存在的最小输入，或明确哪些材料仍待补齐。

## 可选的未来三层结构（不是已部署服务）

| 层 | 可放内容与边界 |
| --- | --- |
| 公开研究仓 | 已许可的代码、素材、真值、协议、合成 fixture 与可复现实验；遵守数据许可 |
| 私有数据层 | 将来新增但未获公开许可的现场数据，只向授权者开放；不影响当前已许可素材的公开状态 |
| 独立盲评服务 | 将来使用未暴露真值的新留出集，仅返回约定分数；需另行落实 runner、隐私、预算与攻击防护 |

不要求为了分层重写既有 Git 历史、删除已许可数据或更改仓库可见性。
任何这类迁移都是单独决策，不由本文自动执行；公开过真值的数据也不能借分仓恢复盲性。
