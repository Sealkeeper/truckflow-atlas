# 贡献指南（对外版草稿）

## 这个项目在做什么

双机位（南 / 北，同一通道两端）多路摄像头，用**多模态大模型 + 非学习型几何**回答两件事：

1. **这一时刻南、北各有几辆车，其中几辆是同一辆车（重合）** —— 数量全对率
2. **哪几辆车是同一辆** —— 重叠车辆身份全对率

## 硬性规则（不接受讨论，PR 违反直接关闭）

1. **禁止 YOLO 及同类通用目标检测/分割模型**（YOLO 全系、DETR/RT-DETR、Faster R-CNN、SSD、SAM/SAM2 等）。
   不得作为候选框生成器、预标注、蒸馏教师或指标来源。这是项目发起人的明确要求，不是偏好。
2. **不得提交任何真实监控截图、车牌、箱号、客户现场画面**。
3. **不得提交密钥**。CI 会扫描；命中即拒绝。
4. **数字必须带分母**。写"准确率 90%"而不给分子分母的 PR 不予受理。

## 允许的技术路线

- VLM 输出（提示词设计、输出契约、结构化校验）
- 非学习型几何：投影、序数对齐、动态规划、聚类、区间运算、单应（在有标定的前提下）
- 评测器、指标、统计、可视化、性能工程

## 提交什么最有价值

| 类型 | 例子 | 需要附 |
| --- | --- | --- |
| 评测漏洞 | 「某输入能让数量全对率虚高」 | 最小复现 JSON |
| 指标歧义 | 「部分遮挡时重叠边该不该连」 | 判定表 + 理由 |
| 算法改进 | 新的保序对齐代价函数 | 离线结果 + 分母 |
| 性能 | 把每帧请求的 tokens 降下来且不掉点 | 前后对比与硬件 |

## 结果怎么写

用这个模板，缺一项就不算完成：

```
口径：<数量全对率 / 身份全对率>
分子/分母：x / N
数据：<合成 / 开发集 / 盲测集>，sha256
对照：<基线配置与它的分数>
结论：GO / NO-GO，以及它在哪些情况下会失败
```

**只报好消息的 PR 会被退回。** 我们更看重"它在哪里失效"。
