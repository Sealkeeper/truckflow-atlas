# 公开协作入口

贡献规则统一维护在根目录 [CONTRIBUTING.md](../../CONTRIBUTING.md)，避免两份指南漂移。

2026-10-23 澄清后的核心边界：

- **实时视频解析链路不依赖 YOLO 及同类检测器**，远端或异步在线调用也算依赖。
- **离线教师、辅助预标注、候选挖掘与蒸馏研究允许探索**；学生的实际部署结构仍须满足实时约束。
- 教师预测不是人工 gold，不得改写冻结真值、泄漏留出集或用教师给自己打分。
- 不限制为当前 VLM + 几何实现；跨领域机制也可提案，执行前说明许可、资源 / 费用和停止条件。
- 已发布素材按 [DATA_LICENSE.md](../../DATA_LICENSE.md) 使用；不擅自上传新的现场敏感数据、密钥或凭证。

请在 PR 中说明贡献类型、实际检查与失败条件。视觉结果须有分子 / 应评分母、数据版本与 hash，
未测写“未测”；文档 / 工程贡献可写“不适用”，不以维护测试冒充识别效果。

默认离线自检命令和审计结果保护要求见 [提交前自检](../../CONTRIBUTING.md#提交前自检)。
