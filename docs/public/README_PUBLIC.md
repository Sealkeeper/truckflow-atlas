# TruckFlow Atlas

**用多模态大模型 + 几何约束，做双机位货车计数与跨镜同车识别。**

这个仓库公开的是**方法、评测协议和工具**，不含任何真实监控画面或客户数据。

## 问题是什么

一条单车道物流通道，两端各一台摄像机（南、北），镜头朝向相反。给定同一秒的两帧，要回答：

| 指标 | 定义 |
| --- | --- |
| **数量全对率** | 南、北、重合三项计数**同时**正确的时刻数 / 应评时刻数 |
| **重叠车辆身份全对率** | 同画面重叠边集合与南北同车配对集合**完全一致**（无错配、无一对多）的时刻数 / 应评时刻数 |

难点不在"数车"，在：

- 两辆车**并排/遮挡**时会不会被数成一辆
- 一辆车的**驾驶室和车厢**会不会被数成两辆
- 同一辆车在南北两侧**是不是同一个人**（跨镜去重）
- 远处的**货堆、货架、阴影**会不会被当成车

## 技术约束（很重要）

本项目**不使用 YOLO 或任何通用目标检测/分割模型**。候选由多模态模型给出，
后续全部走非学习型几何与结构化规则。原因：目标场景里车顶/货堆/集装箱的视觉特征高度相似，
检测器的先验反而会制造系统性误差，而且项目要求每一步都能被审计。

## 快速开始

```bash
python -m pytest -q coord/evaluation-v3/tests
python coord/optimization-20261022/audit/run_audit.py
```

两条都必须通过，否则你的改动会让指标失真。

## 我们特别欢迎的贡献

1. **找出评测器的漏洞**——能让错误预测拿到 100% 的输入，最有价值。
2. **指出指标定义里的歧义**——比如"只露车尾算不算一辆车"。
3. **替换掉某个经验阈值**——用可推导的结构约束替代调参。
4. **把每帧成本降下来**且不掉点。

请先读 [CONTRIBUTING.md](./CONTRIBUTING.md)。我们只接受带**分子分母**和**失败条件**的结果。
