# TruckFlow Atlas

**用多模态大模型 + 几何约束，做双机位货车计数与跨镜同车识别。**

这个仓库公开**方法、评测协议、工具，以及已获准公开的监控素材与人工复核真值**。
使用范围与隐私限制见 [DATA_LICENSE.md](../../DATA_LICENSE.md)；这不授权上传新的敏感现场数据。
当前状态、结果与复现边界统一以根目录 [README.md](../../README.md) 为准。

## 问题是什么

一条单车道物流通道，两端各一台摄像机（南、北），镜头朝向相反。给定同一秒的两帧，要回答：

| 指标 | 定义 |
| --- | --- |
| **数量全对率** | 南、北、重合三项计数**同时**正确的时刻数 / 应评时刻数 |
| **重叠车辆身份全对率** | 同画面重叠边集合与南北同车配对集合**完全一致**（无错配、无一对多）的时刻数 / 应评时刻数 |

难点不在"数车"，在：

- 两辆车**并排/遮挡**时会不会被数成一辆
- 一辆车的**驾驶室和车厢**会不会被数成两辆
- 南北两侧的候选**是不是同一辆物理车**（跨镜去重，不识别人）
- 远处的**货堆、货架、阴影**会不会被当成车

## 技术约束（很重要）

限制针对**实时视频解析链路不依赖 YOLO 及同类检测器**，不禁止离线教师、辅助预标注或蒸馏研究。
当前 VLM + 非学习型几何只是实现路线，不是研究白名单；也不把检测器“必然更差”当作未经验证的结论。
部署依赖、教师 / 学生边界和独立评测要求见 [贡献指南](../../CONTRIBUTING.md#实时部署与离线研发的边界)。

## 快速开始

```bash
python -m pytest -q coord/evaluation-v3/tests
```

其他审计可能写入结果文件，执行前按 [贡献指南](../../CONTRIBUTING.md#提交前自检) 保护原证据。

## 我们特别欢迎的贡献

1. **找出评测器的漏洞**——能让错误预测拿到 100% 的输入，最有价值。
2. **指出指标定义里的歧义**——比如"只露车尾算不算一辆车"。
3. **替换掉某个经验阈值**——用可推导的结构约束替代调参。
4. **把每帧成本降下来**且不掉点。

请先读 [CONTRIBUTING.md](./CONTRIBUTING.md)。我们只接受带**分子分母**和**失败条件**的结果。
