# 公共工作区

这是所有会话唯一共享的项目入口和通信媒介。

## 目录

- `app/`：Web 应用（浏览器端页面与本地 API 服务）
- `pipeline/`：多模态识别、抽样、共识、去重、评测流程
- `docs/`：需求、架构、准确率协议与接口契约
- `data/`：小体积样本、标注、分析结果（大视频不入库）
- `assets/`：截图与样张
- `coord/<role>/STATUS.md`：各会话公开状态；其他会话只读
- `sessions/`：各会话私有工作区，禁止跨会话读取

## 协作规则

1. 原始数据底座只读，不复制、不移动、不修改其中任何文件。
2. 不把 API Key、原始大视频、用户隐私素材提交到 Git。
3. 识别结论必须带证据：机位、视频时间、车辆框、裁剪图、模型票数与复核状态。
4. 无法确认就标记 `review`，不能为了“数字好看”猜一个确定答案。
5. 每个会话只写自己负责的目录，并在 `coord/<role>/STATUS.md` 公布接口、完成项、阻塞项。
