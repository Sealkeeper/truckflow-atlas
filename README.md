# TruckFlow Atlas

**双机位货车计数与跨镜同车识别**：一条单车道通道，两端各一台摄像机（南 / 北，镜头朝向相反），
给定同一秒的两帧，回答"各有几辆车、其中几辆是同一辆"。

做法是**多模态大模型给候选 + 非学习型几何做约束与去重**。本项目**不使用 YOLO 或任何通用目标检测/分割模型**。

## 两个指标（只看这两个）

| 指标 | 定义 |
| --- | --- |
| **数量全对率** | 南、北、重合三项计数**同时**正确的时刻数 / 应评时刻数 |
| **重叠车辆身份全对率** | 同画面重叠边集合与南北同车配对集合**完全一致**（无错配、无一对多、无重复多配）的时刻数 / 应评时刻数 |

唯一数按 `unique = south + north − overlap` 校验，不单独作为第三项。

## 当前成绩（诚实版）

| 项 | 数值 | 说明 |
| --- | --- | --- |
| 数量全对率（开发集 10 时刻） | **7/10** | 最好组合；对参数扰动**不稳定**（6,561 组扰动中仅 11.7% 达到 ≥7） |
| 单机位计数 exact | **19/20** | "凡模型自己明确排除过的对象就删"之后 |
| 重叠车辆身份全对率 | **未测** | 缺人工 gold，任何身份准确率的说法目前都不可信 |

我们不宣称"已经 100%"。目标是先在冻结盲测集上做到，再谈泛化。

## 数据就在这个仓库里

**监控帧与人工复核过的真值全部公开**（`assets/frames/`、`accuracy/reviewed/`、`review/`），
目的就是让别人能核对我们的数、指出我们的错。适用 `DATA_LICENSE.md`：
可用于研究与复核，不得用于识别特定自然人。

## 快速开始

```powershell
python -m http.server 4173 --bind 127.0.0.1   # 打开复核工作台 http://127.0.0.1:4173/
python -m pytest -q coord/evaluation-v3/tests
python coord/optimization-20261022/audit/run_audit.py
```

评测器红队必须 0 失败，否则你的改动会让指标失真。

## 目录

| 目录 | 内容 |
| --- | --- |
| `coord/evaluation-v3/` | 评测协议、评测器、红队用例 |
| `coord/optimization-20261022/` | 标注台、指标定义、实验契约、失败解剖、任务队列 |
| `invention/lane_queue/` | 1D 队列 + 保序对齐原型（当前最佳路线的实现） |
| `research/` | 路线调研与**证伪记录**（大量 NO-GO，含原因） |
| `accuracy/` | 历史实验与人工复核真值 |
| `assets/frames/` | 南北双机位原始帧 |
| `docs/public/` | 对外协作文档（贡献指南、发布清单、协作桥方案） |

## 想帮忙？从这里开始

1. **找出评测器漏洞**——能让错误预测拿到满分的输入，最有价值。
2. **指出指标歧义**——例如"只露车尾算不算一辆车"。
3. **用结构约束替换经验阈值**——我们的教训是：18 条纯几何规则里最好的一条能命中全部伪框，却误删 29/74 台真车。
4. **把每帧 tokens 降下来**且不掉点。

先读 [CONTRIBUTING.md](./CONTRIBUTING.md)。只接受带**分子分母**和**失败条件**的结果。

## 双机位工作台

仓库根目录的纯静态工作台可直接打开 `index.html`，推荐用上面的 `http.server` 启动。
右上角"复核画面"打开人机复核模态：左南右北、固定通道裁剪、南/北/重合/去重四列输入，
以及原图、连续帧和 30 秒视频证据。数量默认标为"AI 初标"，必须人工终审。
