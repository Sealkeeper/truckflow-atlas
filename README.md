# TruckFlow Atlas

**双机位货车计数与跨镜同车识别**：一条单车道通道，两端各一台摄像机（南 / 北，镜头朝向相反），
给定同一秒的两帧，回答"各有几辆车、其中几辆是同一辆"。

**方案约束**：实时视频解析链路不依赖 YOLO 及同类检测器。当前最好方案由非学习型几何生成南北实例与候选对，
多模态模型只判断同车关系并给出证据，代码侧完成合同校验、一对一匹配与去重。离线教师、辅助预标注与蒸馏研究可以开展，
但教师输出不能替代人工真值，学生部署仍须满足实时约束。详见 [贡献指南](./CONTRIBUTING.md#四条硬规则)。

## 两个指标（只看这两个）

| 指标 | 计算公式 | 判定 |
| --- | --- | --- |
| **数量全对率** | $\frac{1}{N}\sum_{i=1}^{N}\mathbf{1}\{(s_i,n_i,o_i)=(s'_i,n'_i,o'_i)\}$ | 南、北、重合三项计数**同时**正确 |
| **重叠车辆身份全对率** | $\frac{1}{N}\sum_{i=1}^{N}\mathbf{1}\{(E_i,P_i)=(E'_i,P'_i)\}$ | 重叠边集合与南北同车配对集合**完全一致**（无错配、无一对多、无重复多配） |

$N=15$ 固定；带单引号的变量表示预测值，`E_i` 为同画面重叠边集合，`P_i` 为南北同车配对集合。缺失、超时或合同失败均计 0，不缩小分母。唯一数按 `unique = south + north − overlap` 校验，不单独作为第三项。

### 此方案介绍

- **分支**：`main`
- **位置**：[`docs/results/2026-10-23-multimodel.md` §2「方案：实例对协议」](https://github.com/Sealkeeper/truckflow-atlas/blob/main/docs/results/2026-10-23-multimodel.md)；证据路径在 §6。
- **选型**：`doubao-seed-2-0-lite-260428`。
- **技术路线**：两层。第一层是关系打分——冻结原图与非学习型几何先产出南北实例和候选对，模型看固定四图只判同车关系，不输出 bbox，代码侧做合同校验、一对一匹配与去重；第二层是证据复核——在候选对存在竞争的 7 个时刻，让模型按颜色、挂车类型、货物、标记、损伤、窗顶、附属件等线索族给出 `same/different/abstain` 与冲突线索，只接受「至少两个独立线索族一致且无冲突线索」的边，并且必须构成合法一对一，否则整格回退第一层结果。
- **结果口径**：开发集 15 个复核时刻、固定分母。基线单轮 12/15 与 11/15；证据复核层实际跑了 6 格 `t0005/t0177/t0470/t1113/t2600/t1500`（其中 `t1500` 属事后指名的 gold-informed 补格，`t1200/t1800` 未跑、按基线保留），合并后 14/15 与 13/15。标签 `DEV_ONLY_POSTHOC_EVIDENCE_V4`，事后合并、非盲测、非 100%。
- **局限**：`t1500` 的复核边把数量由对判错，说明证据层在「两辆外观接近」时会反向伤害计数；`t1113` 首次请求为传输失败（0 字节），重发一次才拿到合同通过的回包。

## 数据就在这个仓库里

**本仓库已包含获准公开的监控帧与人工复核真值**（`assets/frames/`、`accuracy/reviewed/`、`review/`），
目的就是让别人能核对我们的数、指出我们的错。适用 `DATA_LICENSE.md`：
可用于研究与复核，不得用于识别特定自然人。

## 快速开始

```powershell
python -m http.server 4173 --bind 127.0.0.1   # 打开复核工作台 http://127.0.0.1:4173/
python -m pytest -q coord/evaluation-v3/tests
```

默认测试不发模型请求。需要复算其他审计时，先按 [贡献指南](./CONTRIBUTING.md#提交前自检) 保护原证据；
合成测试通过不等于真实视觉准确率提高。

## 想帮忙？从这里开始

1. **找出评测器漏洞**——能让错误预测拿到满分的输入，最有价值。
2. **指出指标歧义**——例如"只露车尾算不算一辆车"。
3. **用结构约束替换经验阈值**——我们的教训是：18 条纯几何规则里最好的一条能命中全部伪框，却误删 29/74 台真车。
4. **把每帧 tokens 降下来**且不掉点。

先读 [CONTRIBUTING.md](./CONTRIBUTING.md)。只接受带**分子分母**和**失败条件**的结果。

## 双机位工作台

仓库根目录的纯静态工作台可直接打开 `index.html`，推荐用上面的 `http.server` 启动。
右上角"复核画面"打开人机复核模态：左南右北、固定通道裁剪、南/北/重合/去重四列输入，
以及原图、连续帧和 30 秒视频证据。数量默认标为"AI 初标"，必须人工终审。
数量复核与身份 pair 复核分开，两者目前都已完成 15 个时刻；身份判断不能从
数量表反推。
